# Carebridge - Connecting families with care
Care marketplace connecting patients with verified bystanders

A two-sided service marketplace connecting patients with verified bystanders for hospital and home care support.

## 🌟 Features

- **Patient Registration** - Sign up with OTP, email verification, address, and preferences
- **Bystander Registration** - Complete KYC (Aadhaar, PAN, Bank, Selfie, Experience)
- **Live Tracking** - GPS location sharing and real-time updates (Coming soon)
- **Secure Payments** - UPI, Cards, Net Banking via Razorpay/Cashfree (Coming soon)
- **Ratings & Reviews** - Patient and bystander rating system
- **Admin Panel** - Verify KYC, manage bookings, commissions, and reports
